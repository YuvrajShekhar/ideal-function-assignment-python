# Results Directory

This directory contains all output files generated by the analysis pipeline.

## Contents

### Database Files
- **assignment_data.db** - SQLite database containing:
  - `training_data` table: 400 rows, 5 columns
  - `ideal_functions` table: 400 rows, 51 columns
  - `test_results` table: Mapped test points with deviations

### Visualizations
Generated plots in PNG format:
- **training_vs_ideal.png** - Training functions with best-fit ideal functions
- **test_mapping.png** - Test data mapping results (mapped vs unmapped)
- **deviation_analysis.png** - Deviation scatter plot
- **complete_dashboard.png** - Comprehensive 4-panel dashboard

## Usage

These files are automatically generated when running:
```bash
python main.py
```
